Modelagem de dados

  • Oficial: BCB (Selic, IPCA)
  • Mercado: preços e índices via API
  • Consolidado: cópia diária de DY/agenda (Status Invest / feed autorizado)
  • Editorial: Suno e InfoMoney (contexto, não banco)

O que este MVP entrega

  • Contrato JSON em /data/
  • Calculadora ilustrativa vs benchmarks
  • Radar (placeholder até o collector)
  • Fronteira clara com a Velumetric

Como se relaciona com a Velumetric

Velumetric = cripto, score e digest. Divmetric = dividendos e projeção em reais. Productos, schemas e login ficam separados; só há link cruzado.
